# Aqsha Qadagalau — контроль денег

Android-приложение для учёта расходов и доходов (Kotlin + Jetpack Compose). Работает офлайн, данные хранятся на телефоне.

## Что умеет

- **Главная** — кольцевая диаграмма расходов за месяц, иконки категорий вокруг (нажмите на иконку — добавить расход в эту категорию), доход / расход / баланс, кнопки «−», «+» и микрофон.
- **Голосовой ввод** — скажите, например, «Такси 1500, обед 3200 и зарплата 250 тысяч». Приложение само разделит фразу на записи, определит доход это или расход, подберёт категорию и пересчитает баланс. Понимает «тысяч / мың / bin / thousand», «млн». Распознавание идёт на выбранном языке приложения.
- **Категории** — любые свои категории расходов и доходов: название, 47 иконок, 18 цветов. Встроенные можно переименовать или удалить.
- **Постоянные расходы** — отдельный раздел: кредиты, еда, коммунальные услуги, другое. День оплаты, напоминание «через N дней / просрочено», кнопка «Оплатить» сама записывает расход.
- **Аналитика и советы** — куда уходит больше всего денег (доли, сравнение с прошлым месяцем), доля сбережений, средний расход в день, прогноз на месяц и персональные советы по экономии.
- **История** — все записи по дням; нажмите на запись, чтобы удалить.
- **Настройки** — язык (қазақша, русский, English, Türkçe), валюта (₸, ₽, $, ₺) с редактируемыми курсами, цвет интерфейса и цвет текста (готовые цвета или свой HEX), тёмная тема, сброс данных.

## Как получить APK

### Вариант 1 — без программ, через GitHub (бесплатно)
1. Создайте аккаунт на github.com и новый репозиторий.
2. Загрузите в него все файлы из этой папки (кнопка «Add file → Upload files», вместе с папками `.github`, `app`, `gradle`).
3. Откройте вкладку **Actions** — сборка запустится сама (~5–8 минут).
4. Когда появится зелёная галочка, откройте сборку и скачайте **AqshaQadagalau-apk** внизу страницы. Внутри — `app-debug.apk`.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2 — Android Studio
1. Установите Android Studio (Ladybug или новее).
2. File → Open → выберите папку `AqshaQadagalau`.
3. Дождитесь синхронизации Gradle и нажмите ▶ Run (телефон по USB или эмулятор).
   Или Build → Build App Bundle(s) / APK(s) → Build APK(s).

## Требования
- Android 8.0 и новее.
- Для голосового ввода нужно приложение Google (служба распознавания речи). Если её нет, фразу можно ввести текстом на том же экране.

## Структура
```
app/src/main/java/kz/aqsha/qadagalau/
  MainActivity.kt          навигация, боковое меню
  data/                    модели, хранилище, статистика, советы, разбор голоса
  i18n/Strings.kt          все тексты на 4 языках
  ui/                      экраны и тема
app/src/main/res/          иконка приложения и название
```
